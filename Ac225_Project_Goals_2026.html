One-Pager Study Guide

Plain-English meanings for meeting and judging preparation.

Your seed-42 answer

“Seed 42 is the fixed random-number setting used for my final training run. It makes initialization and sampling reproducible. The number 42 has no scientific meaning. Because I currently have one independently trained seed, this result applies to that run and does not prove the LSTM always wins.”

Seed 42

An arbitrary fixed starting setting for computer randomness. It helps repeat the run; it is not 42 experiments or the best of 42 models.

Frozen checkpoint

Saved model weights that were no longer changed before final testing.

V3 surrogate

The third version of a fast approximation trained to imitate the slower reference calculation.

Physics-informed

The governing equations contribute to training loss. This guides learning but does not guarantee that every prediction is physically correct.

LSTM / recurrent model

A Long Short-Term Memory network that carries an internal state through a sequence. It is not human-like thinking or memory.

MLP

A standard feedforward neural network without recurrent sequence memory.

Parameter-matched control

The LSTM and MLP were kept close in learned-weight count and used the same data, loss, schedule, and evaluation so architecture was the main intended difference.

Epoch / batch / loss

An epoch is a training cycle through batches; a batch is a subset processed together; loss is the penalty the optimizer tries to reduce. Six thousand epochs are not 6,000 experiments.

Endpoint objective

A training penalty that gives special attention to the final Ac-225 inventory.

Five-nuclide reduced system

A simplified chain tracking Ra-226, Ra-227, Ac-227, Ra-225, and Ac-225. It is not a complete reactor model.

Inventory / transmutation

Inventory means number of atoms. Transmutation means changing one nuclide into another through a nuclear reaction or decay.

Cross section / neutron spectrum

Cross section measures how likely a reaction is at a given energy. A spectrum describes the distribution of neutron energies.

Two-group representation

A detailed neutron spectrum compressed into two energy ranges or features.

Bateman equations / Radau

Bateman equations describe coupled production and decay. Radau is a high-accuracy numerical ODE method used as a reference check.

Physics residual / nonnegativity

Residual is mismatch with the governing equation. Nonnegativity means isotope inventories should not become negative.

Shielding and self-shielding

Material changes neutron reaction rates by absorbing or attenuating neutrons. The current project represents this only in a simplified way.

Locked shifted test

A test not used for training or tuning, with conditions intentionally different from the training distribution.

Mesh

The number of time-query points: 32, 48, 64, or 96. It is not a spatial reactor grid.

Worst-mesh median

Calculate the median error at every mesh size and report the largest median.

Positive-case mask

The headline percentage scores cases above the stated Ac-225 truth threshold. Zero and very-low cases must be reported separately.

Relative error / denominator floor

Prediction difference divided by the reference, with a 10^12-atom floor to prevent tiny references from creating extreme percentages.

Median / p95 / tail

Median is the middle error, not the average or worst. p95 is the level below which about 95% of cases fall. The tail is the difficult high-error end.

Paired comparison

Compare LSTM and MLP errors on the same scenario before summarizing their difference.

Percentage points

An absolute difference between two percentages. A 0.63-point improvement is not the same as a 0.63% relative improvement.

Bootstrap 95% confidence interval

A range estimated by repeatedly resampling test scenarios. It describes uncertainty in the statistic, not where 95% of individual errors fall.

Inconclusive below-3% gate

The shifted point estimate was below 3%, but its confidence interval extended above 3%, so the data did not establish that claim.

False positive

The model predicts production when the reference value is exactly zero.

Synthetic benchmark

A benchmark generated using equations and nuclear-data inputs, not a physical irradiation measurement.

External validation

Testing the already-frozen model against independent experimental measurements or a separate trusted high-fidelity calculation.

ORIGEN / OpenMC

Established tools for isotope depletion and particle transport. Agreement would strengthen evidence but still needs clearly stated assumptions.

FP64 / numerical precision

Sixty-four-bit arithmetic and close agreement between calculations. Numerical agreement is not experimental or reactor accuracy.

Provenance / SHA-256 hash

Provenance records where artifacts came from. A hash fingerprints an exact file but does not prove the science is correct.

Clinical validation / production-ready

Evidence for patient treatment or operational decisions. The current project has neither and should not use these labels.

Safest current claim

For one reproducible seed, V3 achieved a 0.97% matched positive-case worst-mesh median and beat the matched MLP. Shifted evidence remains inconclusive and experimental validation is still needed.

Solutions When Something Is Blocked

Use the fallback without changing the scientific label.

Jayden meeting is delayed

Send the six questions by email, continue Chapter 4 extraction, and freeze the protocol. Do not delay work that does not require his answer.

Machine-readable Berkeley data is unavailable

Reconstruct only values supported by tables and digitized plots, record digitization uncertainty, and label the result a published-case reconstruction rather than full raw-data validation.

No SCALE or ORIGEN access

Obtain an expert review of the input deck you would use, compare with published depletion results, and list the unavailable independent calculation as future work.

No additional GPU access

Keep the claim single-seed and do not run the ablation. A transparent limitation is better than an underpowered or unaffordable experiment.

Berkeley inputs do not fit V3

Report exactly which input is outside the frozen model contract. Validate reaction rates or decay/activity conversion separately instead of forcing an invalid end-to-end number.

External prediction performs poorly

Preserve the result, diagnose the mismatch, and make transfer failure part of the conclusion. Do not tune V3 on the external answer and call it validation.
