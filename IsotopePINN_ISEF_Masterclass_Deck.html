Retrieval drill
Why does (n,2n) change Ra-226 to Ra-225, while beta-minus decay changes Ra-225 to Ac-225?
Reveal answer
The first reaction absorbs one neutron and emits two, lowering mass number by one while staying radium. Beta-minus converts a neutron to a proton, preserving mass number but changing the element to actinium.

Say it aloud

Fast neutrons convert Ra-226 into Ra-225 through (n,2n). Ra-225 then beta decays into Ac-225.

Ac-227 wording

Call it a long-lived tracked impurity concern. Do not quote one universal safe percentage.

Module 2 / Quantities

Four equations carry most of the physics

Decay constant

λ = ln(2) / T1/2

If half-life is in hours, lambda is in h-1.

Activity

A = λN

One becquerel is one decay per second. Activity is a rate, not simply an amount.

Reaction rate

k(E) = φ(E)σ(E)

Flux times cross section gives interaction probability per target atom per time. One barn is 10-24 cm2.

Spectrum average

σ̄ = [∫σ(E)φ(E)dE] / [∫φ(E)dE]

A real neutron field contains many energies, so the cross section must be weighted by the spectrum.

Berkeley distinction: produced atoms, end-of-bombardment activity, activity after cooling, and activity recovered after chemistry are different quantities.
Retrieval drill
What must you know before converting activity into atoms?
Reveal answer
The isotope half-life or decay constant, activity units, and exact reference time. Then use N = A/lambda with consistent units.

Unit check

Flux is n cm^-2 s^-1 and cross section is cm^2, so their product is s^-1 per target atom.

Common trap

A timestamp or recovery mismatch can look like model error. Always name the isotope and time attached to an activity.

Module 2 / Calculus

Every equation is "sources minus sinks"

A derivative is the instantaneous rate at which an isotope inventory changes.

Start with Ac-225: it rises when Ra-225 decays into it and falls when Ac-225 itself decays.
dNAc225/dt = λ225N225 - λAc225NAc225
dN226/dt = -(λ226 + k2n + kγ)N226
dN225/dt = k2nN226 - λ225N225
dNAc225/dt = λ225N225 - λAc225NAc225
dN227/dt = kγN226 - λ227N227
dNAc227/dt = λ227N227 - λAc227NAc227

Compact form: dN/dt = MN, where M stores all source and sink coefficients.

Model boundary: this reduced chain omits detailed neutron transport, many reactions and daughters, chemistry, heat, shielding, and delivery.
Retrieval drill
Derive the Ra-225 equation from the reaction diagram.
Reveal answer
Ra-225 is created by (n,2n), giving +k2n N226, and lost through its own decay, giving -lambda225 N225.

How to rebuild a row

Draw every arrow into an isotope as a positive source and every arrow out as a negative sink.

Branch factors

The displayed equations are the simplified form. The code can include declared branching or yield factors where needed.

Module 3 / From zero

Translate every ML word into an action

Feature

An input, such as energy, time, flux, distance, or initial inventory.

Target

The answer to predict, such as a trajectory or reaction rate.

Loss

A number measuring wrongness. Training adjusts weights to lower it.

Epoch

One pass through training data. More epochs do not guarantee a better model.

Checkpoint

Saved weights from one training time, selected using declared development data.

Overfitting

Training performance improves while performance on new cases gets worse.

One training step: predict, compare, differentiate, update.
LSTM is not human thinking. "Long Short-Term Memory" is a gated recurrent network that carries numerical state through a sequence.
Retrieval drill
Explain a feature, target, loss, epoch, and checkpoint without using another unexplained buzzword.
Reveal answer
Inputs go into the model, targets are desired answers, loss scores errors, an epoch is one data pass, and a checkpoint is saved numerical weights.

Say it aloud

The network is a flexible mathematical function. Training selects its numerical weights; it does not discover physical truth automatically.

Why stop early

Validation can stop improving while training loss falls, which signals overfitting.

Module 3 / Experimental design

Good testing prevents accidental cheating

Train

Fits model weights.

Selection

Chooses checkpoint or settings.

Calibration

Sizes uncertainty intervals, not the mean model.

Test

Judges after choices are frozen.

Seed 42

A random seed fixes pseudorandom initialization and data order. It is not a physics constant. Multiple seeds test dependence on luck.

Best epoch

Choosing it is valid if the rule uses validation data and was declared before the final test. Reusing test answers to choose it causes leakage.

Your boundary: V3's strongest result is one independent seed. V4 used five LSTM seeds. The V4 48-case set was locked for V4 but appeared in an earlier V2 diagnostic, so it is not completely untouched external data.
Retrieval drill
What is the difference between a seed, checkpoint, and frozen model?
Reveal answer
A seed controls pseudorandom choices; a checkpoint is saved weights; freezing means weights and decision rules stop changing before evaluation.

Memory hook

Train learns. Selection chooses. Calibration sizes intervals. Test judges.

Why five seeds

They show sensitivity to initialization, and their disagreement can help estimate model uncertainty.

Module 4 / Architecture and loss

How V3 makes a physics-guided trajectory

Input

Scenario

Time, flux, energy feature, and five starting inventories.

Encoding

Fourier features

Sine/cosine bands expose multiple time and energy scales.

Sequence

Two-layer LSTM

Hidden size 256 carries numerical state across 64 time points.

Output

Softplus

Keeps all five predicted inventories nonnegative.

Structure

Hard IC

Forces the prediction to equal the input inventory at time zero.

N(t) = [1 - α(t)]N(0) + α(t)Nnetwork(t), where α(0) = 0

Data loss

Compares predictions with Radau-generated trajectories.

Integrated physics loss

rk = Nk+1 - Nk - (Δt/2)[f(Nk) + f(Nk+1)]

Penalizes interval imbalance in the Bateman equations.

Technical limit: the trapezoidal residual is approximate and can struggle on long log-spaced intervals for 42.2-minute Ra-227. The code contains a later exact-exponential option, but it must not be attached to a frozen run unless that run configuration used it.
Retrieval drill
Explain Fourier features, LSTM memory, softplus, hard IC, and physics loss in one sentence each.
Reveal answer
Fourier features expose input scales; the LSTM carries state; softplus prevents negatives; hard IC fixes time zero; physics loss penalizes equation imbalance.

Physics-informed does not mean perfect

The loss enforces only the equations and assumptions included in code, and optimization can still be imperfect.

Correct LSTM wording

Its gates retain or update numerical information; it is not long-term and short-term human reasoning.

Module 5 / Result 2

A useful surrogate must know when not to answer

95.8% joint coverage

For each model, 46 of 48 locked cases contained both true rates.

2.1% raw GP coverage

Only 1 of 48 cases had both rates inside raw plus/minus 2 SD. Calibration was essential.

184 of 184 rejected

Every constructed outside-range case was refused.

0 of 48 rejected

No locked in-domain test family was falsely rejected.

Coverage is not accuracy. Coverage asks whether an interval contains the answer. Accuracy asks how close the point prediction is. Rejection is not OOD accuracy.
Retrieval drill
How are calibration and OOD rejection different?
Reveal answer
Calibration sizes intervals for accepted cases; OOD rejection refuses unfamiliar cases rather than pretending the intervals remain trustworthy.

Two standard deviations

Plus/minus 2 SD is near 95% only under appropriate assumptions. V4 tested the assumption and showed raw GP joint intervals failed.

Correct wording

The guard rejected 100% of explicit OOD cases; it did not predict those cases accurately.
